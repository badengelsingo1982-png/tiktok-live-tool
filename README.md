# Tiktok Infinity

TikFinityと同じ仕組みの自分用ミニ版。ギフト/コメント/フォロー/いいねをリアルタイム受信して、OBS用オーバーレイにアラート表示・効果音・TTS読み上げを行います。

## セットアップ

```bash
npm install
node server.js
```

1. ブラウザで管理画面を開く → http://localhost:8181/dashboard
2. TikTokユーザー名(@なし)を入力して「接続」※**配信中のアカウントのみ接続可能**
3. OBS / TikTok LIVE Studio の「ブラウザソース」に以下を登録
   - URL: `http://localhost:8181/overlay`
   - 幅 1920 / 高さ 1080
4. 管理画面のテストボタンでオーバーレイの動作確認(配信してなくてもOK)

### サブパスで公開する場合

1台のサーバーに複数アプリを載せる時は、環境変数 `BASE_PATH` で公開パスをずらせます。

```bash
BASE_PATH=/tiktok node server.js   # → /tiktok/dashboard, /tiktok/overlay
```

リバースプロキシ側はパスを**そのまま**(プレフィックスを剥がさずに)渡してください。Caddyなら:

```
@tiktok path /tiktok /tiktok/*
handle @tiktok {
	reverse_proxy localhost:8181
}
```

未設定なら従来どおりルート直下(`/dashboard`, `/overlay`)で動きます。

## VOICEVOX（キャラ音声の読み上げ）

読み上げは既定で**端末内蔵の音声**を使います。VOICEVOX ENGINE を動かすと、ダッシュボードからキャラ音声に切り替えられます。

### 1. VOICEVOX ENGINE を起動

**ダッシュボードの「▶ 起動」ボタン**（読み上げ設定 → VOICEVOX の行）で起動できます。SSHに入る必要はありません。押すと以下を自動で行います。

1. Docker が使えるか確認
2. コンテナが未作成ならイメージを取得して作成・起動（初回は数分）／停止中なら起動
3. エンジンが応答するまで待機（最大2分）

進捗はボタン横に表示され、完了すると声のプルダウンにキャラが並びます。ボタンは**管理者アカウントのみ**表示されます。

実行されるコマンドは固定で、画面からの入力は混ざりません。

```bash
docker run -d --restart always --name voicevox -p 127.0.0.1:50021:50021 voicevox/voicevox_engine:cpu-latest
```

手動で起動しても構いません（結果は同じです）。`127.0.0.1:` を付けて**外部に公開しない**こと（付け忘れると誰でも合成し放題になります）。メモリは2GB程度必要です。

> **前提**: ボタンから起動するには、アプリを動かしているユーザーが `docker` を実行できる必要があります（例: `sudo usermod -aG docker $USER` の後に再ログイン）。
> なお docker グループへの追加は実質 root 相当の権限を与えることになります。避けたい場合はボタンを使わず、上のコマンドを手動またはsystemdで起動してください。エンジンさえ動いていればアプリ側の動作は同じです。
> Docker が使えない環境では、ボタン横に「Dockerが使えません」と理由が表示されます。

コンテナ名やイメージを変えたい場合は環境変数 `VOICEVOX_CONTAINER` / `VOICEVOX_IMAGE` で指定できます。

### 2. アプリ側の設定

既定で `http://127.0.0.1:50021` を見に行くので、同じサーバーで動かすなら設定は不要です。別の場所に置くなら環境変数で指定します。

```bash
VOICEVOX_URL=http://127.0.0.1:50021 node server.js
```

起動ログに `VOICEVOX ENGINE 検出: ...` と出れば繋がっています。未検出でもアプリは普通に動き、端末内蔵の読み上げが使われます。

### 3. 使い方

ダッシュボード →「読み上げ設定」→ エンジンで **VOICEVOX** を選択 → 話者を選んで「▶ この声で試聴」。「高さ」「速さ」「音量」はVOICEVOX側にも反映されます。

### 遅延を出さないための作り

- **先読み**: 再生の完了を待たずに次の音声を取得（取得は並列・再生は直列）。2件目以降の通信待ちは前の読み上げ時間に隠れます
- **キャッシュ**: 合成結果を `data/tts-cache/` に保存。ギフトの定型文はほぼ毎回ヒットし、エンジンが落ちていても鳴ります
- **自動フォールバック**: 6秒以内に返らない／エンジンが居ない場合は端末内蔵の読み上げに切り替わるので、**読み上げ自体が止まることはありません**
- **キュー上限5件**: 溜まった分は古い方から捨て、常に「今のコメント」を読みます

### 注意

- **クレジット表記が必須**です（例: 配信の概要欄に「VOICEVOX:ずんだもん」）。キャラごとに規約が異なるので、使うキャラの利用規約を確認してください
- `/tts` はオーバーレイが未ログインで開く都合上、認証なしで公開しています。ユーザーごとに毎分120件までに制限しています

## 検索エンジンに載せない仕組み

「Tiktok Infinity」で検索してもヒットしないよう、三重で塞いでいます(設定は不要、常時有効)。

- **全レスポンスに `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet`** — HTML以外(画像・マニフェスト・JSON)も対象。server.js の最上位ミドルウェア
- **各HTMLに `<meta name="robots" content="noindex, nofollow, noarchive">`** — dashboard / overlay / login
- **`/robots.txt` で全面 Disallow** — サブパス配信時は `/tiktok/robots.txt` として返る

さらに管理画面(`/dashboard`)はログイン必須なので、仮にクロールされても中身には到達できません。外部サイトからリンクを張らない限り発見経路もありません。
※ `/overlay` はOBSのブラウザソースから開く都合で認証を掛けていません(URLを知られなければ実害はありませんが、上記のnoindexで索引からは外れます)。

## 機能

- **ギフトアラート**: 中央上部にポップアップ+効果音+TTS。連打ギフトは確定時のみ表示(重複防止済み)
- **コメント表示**: 左下に最新8件。TTS読み上げ対応(端末内蔵の音声合成 / VOICEVOX を選択可、どちらも無料)
- **フォロー/シェアアラート**
- **いいねカウンター**: 右下に累計表示
- **ギフト別サウンド**: サウンドライブラリの音をギフトごとに割り当て(**最大50個**。同じギフトの音を差し替える分は件数に含みません)
- **管理画面**: 接続状態、視聴者数、いいね数、ダイヤ累計、イベントログ

## カスタマイズ

`config.json` で設定変更(再起動で反映):

| 項目 | 内容 |
|---|---|
| `username` | 接続先TikTokユーザー名 |
| `autoConnect` | 起動時に自動接続 |
| `tts.readComments` | コメント読み上げのON/OFF |
| `tts.rate` | 読み上げ速度 |
| `alerts.gift.minDiamonds` | アラートを出す最低ダイヤ数 |
| `alerts.gift.sound` | 効果音ファイルパス |

効果音は `sounds/gift.mp3` `sounds/follow.mp3` を置くと再生されます。無い場合は自動でビープ音になります。

## 注意事項

- `tiktok-live-connector` は非公式ライブラリです。TikTok側の仕様変更で動かなくなる場合があります(その際は `npm update tiktok-live-connector`)
- 接続にログインは不要ですが、頻繁な接続失敗が出る場合はライブラリのSign Server混雑が原因のことが多いので時間を置いて再試行してください
- OBSのブラウザソースで音が出ない場合: ソースのプロパティで「音声をコントロールする」にチェック、または「ページと相互作用」で一度クリックして音声再生を許可

## 拡張アイデア(次のステップ)

- ギフト目標バー(○○ダイヤでチャレンジ達成、goalUpdate イベント対応)
- 特定ギフトで特定アクション(TikFinityのActions & Events相当)→ server.js の GIFT ハンドラにルール分岐を追加
- VOICEVOX連携で高品質TTS(ローカルでVOICEVOXエンジン起動→ /audio_query & /synthesis を叩く)
- コメントへの自動返信チャットボット(Claude API連携)
